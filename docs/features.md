# Features
Vesperando randomizes many parts of Tales of Vesperia: Definitive Edition, but not all of them. 
This page contains an exhaustive list of targets and properties that vesperando modifies and randomizes.

## Artes
| Property                 | Description                                                                                                          |
|--------------------------|----------------------------------------------------------------------------------------------------------------------|
| Power                    | Power of Arte                                                                                                        |
| TP                       | Cost of Arte to use                                                                                                  |
| Cast Time                | Time before Arte is performed (Magic only)                                                                           |
| Target Type              | Controls target cursor behaviour, including if allies should be targeted, and if only allies/enemies can be affected |
| Learn Conditions         | How the Arte can be learned if at all (Up to 3 learning conditions)                                                  |
| Evolve Conditions        | If the Arte can be used as an alter of another arte, and which skills will trigger the evolution (Up to 4 Skills)    |
| Global Effects           | If an Arte can give a buff (per hit)                                                                                 |
| Physical Attack Modifier | Percentage from base power to apply as a Physical hit                                                                |
| Magic Attack Modifier    | Percentage from base power to apply as a Magic Hit                                                                   |
| VS Enemy Power           | Percentage from base power to apply against specific enemy types                                                     |
| Weather Power            | Percentage from base power to apply during certain weather                                                           |
| Fatal Strike Type        | Type of Fatal Strike that can trigger from the Arte                                                                  |

## Skills
| Property   | Description                                                       |
|------------|-------------------------------------------------------------------|
| SP         | Cost of Skill to equip                                            |
| LP         | LP required to learn Skill                                        |
| Symbol     | Symbol associated with the Skill                                  |
| Parameters | Parameter used by the Skill for its effects (Use varies by skill) |

## Items
| Property  | Description                                                                                                                          |
|-----------|--------------------------------------------------------------------------------------------------------------------------------------|
| Price     | Cost of Item to purchase from Shops with Gald                                                                                        |
| Element   | Element(s) of the Item                                                                                                               |
| Skill     | Skill learnable from the Item, including the percentage modifier for the required LP to learn the skill                              |
| Stats     | Physical and Magical Attack/Defense, Luck and Defense is randomized                                                                  |
| Synthesis | Synthesis Recipes and the required Synth Level and Synth Cost to synthesize the item (Up to 3 Recipes, Up to 6 materials per recipe) |

## Chests
All Chests have randomized items.

## Search Points
All Search Points have randomized items, item pools and appearances.

## Events
Only Arc 1 Main Story events are randomized. Most battle events have been left alone. 
However, battle tutorials are mostly skipped, and they are modified to become normal battles.
